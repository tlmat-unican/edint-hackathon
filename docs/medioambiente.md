# Caso de Uso 2: Sostenibilidad Medioambiental

Conjuntos de datos relacionados con el caso de uso "Sostenibilidad Medioambiental" en la ciudad de Santander.

## Consumo de energía en el norte de España

Información sobre el consumo de energía en el norte de España, proporcionada por VIESGO.

??? info "Clientes de autoconsumo"
    * **Descripción:** En este dataset se muestra el número total de contratos acogidos a autoconsumo por municipio, tanto de tipo individual como colectivo.
    * **Formato:** JSON / CSV / EXCEL
    * **Acceso:** Abierto
    * **Fuente:** VIESGO
    * **Endpoint:** <https://redes-spain.opendatasoft.com/explore/dataset/12-autoconsumo-por-tipologia-viesgo/information/>

??? info "Consumo horario"
    * **Descripción:** En este dataset se representa el consumo horario por municipio/código postal y se construye en base a las curvas de carga horaria recogidas por los contadores inteligentes, salvo en los casos de fallos de comunicación, en cuyo caso se utilizan perfilados de consumo.
    * **Formato:** JSON / CSV / EXCEL
    * **Acceso:** Abierto
    * **Fuente:** VIESGO
    * **Endpoint:** <https://redes-spain.opendatasoft.com/explore/dataset/1-consumo-horario-por-codigo-postal-5-digitos-viesgo/information/>

??? info "Número de contratos activos por municipio y tipología"
    * **Descripción:** Este dataset muestra el número total de contratos activos por municipios y por tipología, diferenciados entre suministros domésticos y no domésticos.
    * **Formato:** JSON / CSV / EXCEL
    * **Acceso:** Abierto
    * **Fuente:** VIESGO
    * **Endpoint:** <https://redes-spain.opendatasoft.com/explore/dataset/puntos-de-suministro-por-tipologia-viesgo/information/>

??? info "Instalaciones de autoconsumo"
    * **Descripción:** En este dataset se muestra el número de instalaciones de autoconsumo por municipio con clientes activos.
    * **Formato:** JSON / CSV / EXCEL
    * **Acceso:** Abierto
    * **Fuente:** VIESGO
    * **Endpoint:** <https://redes-spain.opendatasoft.com/explore/dataset/13-instalaciones-de-autoconsumo-por-tipologia-viesgo/information/>

??? info "Consumo horario Cantabria"

    * **Formato:** JSON / CSV / EXCEL
    * **Acceso:** Abierto

??? info "Consumo horario Otras Provincias"
    * **Descripción:** En este dataset se representa el consumo horario por municipio/código postal y se construye en base a las curvas de carga horaria recogidas por los contadores inteligentes, salvo en los casos de fallos de comunicación, en cuyo caso se utilizan perfilados de consumo.
